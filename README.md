# Dog-API-JDBC-Project
A Complete Java Application using JDBC + MySQL + Dog API Integration
📘 Project Overview

This project integrates the Dog CEO Public API with a MySQL database using Java JDBC.
It allows users to:

Fetch live dog breed, sub-breed, and image data from the API.

Store all data into a relational MySQL database.

Retrieve, display, and filter the data via an interactive command-line menu.
